# Arora Group Website Demo

Responsive multi-page static website for GitHub Pages.

## Included
Home, About, Services, Projects index, individual Bellevue Park Residency and Makasembo Housing Project pages, Insights index, two insight articles, Contact, 404 page, shared CSS/JS, sitemap and robots file.

## Publish using GitHub Pages
1. Create a **public** repository named `arora-group-demo`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. The site will publish at `https://YOUR-GITHUB-USERNAME.github.io/arora-group-demo/`.

## Before launch
- Replace illustrative Unsplash photos with approved Arora Group project photography.
- Verify the exact brand fonts, colour values, logo and all project facts.
- Replace placeholder GitHub username in sitemap and robots.txt.
- Connect the demo contact form to a form endpoint; it currently does not transmit or store enquiries.
- Verify phone, email, statistics, claims, legal information and project descriptions.
- Add a privacy notice and any required consent controls.

This is a static demo; it has no database, admin panel, user accounts or backend form processing.
